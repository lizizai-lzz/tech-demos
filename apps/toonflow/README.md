# toonflow — 双引擎创作工作室（小说 / 短剧 · 空跑版）

浏览器内的 Toonflow 风格工作台，支持两种本地模拟流水线：

| 模式 | 阶段 |
|------|------|
| **写短剧** | 种子 → 大纲 → 角色 → 剧本 → 分镜 |
| **写小说** | 种子 → 设定/世界观 → 章纲(3–5) → 角色 → 正文样章 → **一致性审核 / 敏感话题 / 去AI味 / 质检裁定 / 改写** |

所有「生成」均为 **TypeScript 模板 + 假延迟**，不调用任何付费模型 API，无需 API Key。种子原文在两种模式间共享（≤800 字）。

## 运行

```bash
cd apps/toonflow
bun install
bun run dev
```

浏览器打开终端提示的本地地址（通常为 `http://localhost:5173`）。

其他命令：

- `bun run build` — 生产构建
- `bun test src` — 短剧 + 小说流水线单元测试
- `bun run lint` — Oxlint

## 使用说明

1. 在左侧顶部选择 **写小说** 或 **写短剧**（选择会写入 `localStorage` 键 `toonflow:studio-mode`）。
2. 选择当前模式下的示例项目，或粘贴种子原文；切换模式时默认 **保留当前种子**，不会强制换回示例。
3. 点击 **开始空跑**：画布按阶段依次出现节点与连线。
4. **暂停 / 单步** 控制节奏；点击节点打开详情 Sheet，可本地编辑或对关联阶段 **重新生成此节点**。
5. **导出 JSON** 可下载当前模式下的产物快照（短剧或小说数据结构）。
6. 画布视口与原文片段同样会缓存在 `localStorage`。

### 示例种子

- **短剧**：雨巷重逢、午夜食堂、天台信号
- **小说**：灵力高中·青龙堂（修炼 + 校园黑道）、墨山手记（另可用雨巷/食堂种子写小说流水线）

## 模拟范围（Mock）

- 大纲/章纲：从句子切分与模板句拼装
- 角色：中文姓名频次启发式，2–4 人
- 剧本/样章：固定段落结构 + 种子片段嵌入
- **小说质检环（空跑 · 偏网文容忍）**：样章后跑一致性（**修炼体系 + 堂口势力**，非校规现实主义）、敏感（**仅硬阻断未成年人性相关**；绑架/逼炼/暴力等类型桥段不软化）、狠劲分（标题/钩子）、去 AI 味（说明书腔/学生会演讲腔）；裁定 `accept | polish | rewrite` 后本地改写终稿
- 分镜：每场一条卡片（色块占位，无真实图像）
