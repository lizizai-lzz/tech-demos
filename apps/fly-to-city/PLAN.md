# Fly to City — 彩色地图城市

## Goal
从地球第一人称冲进一座能一眼读出道路、水系和绿地的彩色城市，最后停在定稿的斜俯视机位。

## MVP（in）
1. MapLibre 地球 + OpenFreeMap；Photon 搜索和 8 个地标。搜索或点地标后，镜头沿弧线飞向目的地。
2. 飞行是第一人称：速度线从目的地散开、穿过云层、速度最高时视场略拉开，再沿同一俯角减速收进城市。呼啸声用 WebAudio 合成，面板可静音。离线成片走同一条时间轴。
3. 落地后全屏 three.js 城市。地面是 OpenFreeMap 矢量（道路按等级、水系、公园、广场）叠在 EOX Sentinel-2 cloudless 2020 卫星底图上，烘焙成贴图。楼高管线保持不变。默认彩色立面（蓝灰玻璃幕墙、砖住宅、混凝土、深色屋顶），白模只做开关。
4. 暖色阳光、真实阴影、天光渐变、地平线薄雾、玻璃轻微泛光、公园和沿街更多树。斜俯视慢环绕，俯角与东京定稿一致，不抬头。
5. 标题、可折叠面板、录制模式，以及 `render:16x9` / `render:9x16` / `render:preview`。

## Outs
剖切、地层沙盘、付费 3D Tiles、Google / Esri / Mapbox / 百度 / 高德影像、后端、移动端深度适配。

## Tasks
1. 地面：卫星底图 + 高对比矢量（沥青路、车道线、人行道、蓝水、绿地、广场），烘焙进 three.js 地面，阴影仍落在贴图上。
2. 城市外观：蓝灰幕墙、暖色住宅、深色屋顶、暖光、天空和泛光、按绿地加密的树。白模保留为开关。
3. 飞行：第一人称冲刺、速度线、云层、视场和呼啸声，接到交互飞行和离线时间轴（含减速俯冲，俯角不变）。

## Stack rationale
- Bun + Vite + React：与仓库里其他 demo 一致，`bun run dev` 即可。
- MapLibre + OpenFreeMap：地球和矢量地面，不依赖商业底图。
- EOX Sentinel-2 cloudless：CC BY 4.0 的卫星底图，只作烘底层。
- three.js / R3F：城市、阴影、N8AO，以及飞行时的速度线和云。
- WebAudio：呼啸声现场合成，没有音频文件。
- shadcn/ui：搜索和开关面板。

## Deferred
瓦片流式加载、GLB 导出、夜景、配乐卡点、逐车道标线、PLATEAU LOD2 贴图（和挤出体不是同一套几何）。
