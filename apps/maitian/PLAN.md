# maitian — 七平台内容分发监控大屏（空跑版）

灵感来源（形态与交互，**不克隆上游发布中控、不接真实平台、不搬采集实现**）：

- [CzzzzzzJ/mdldm-maitian](https://github.com/CzzzzzzJ/mdldm-maitian) — 麦田：自媒体多平台发布中控与数据监控（MIT）
- 配套发布助手不在本 demo 范围内
- 书签帖：[被问爆的 AI 自媒体工作台，我直接开源了](https://x.com/czzzzzzJ_/status/2122266042491642027)（@czzzzzzJ_，开源数日已破千 Star；帖子约 2k 赞 / 4k 收藏）

本 demo 在浏览器里用 **自写假数据** 演示「一张大屏看七个平台 + 日历排期 + 同龄复盘 + 转化漏斗」；**不登录任何平台、不用 Chrome/CDP/插件填上传页、不采集创作者后台、不发飞书、不镜像上游仓库**。

## Goal

单页内容运营工作台：用一份演示数据，把七个平台的粉丝与播放汇总在一张大屏上，并能点进日历、单期复盘和转化漏斗。

## MVP

### In

- 顶栏：麦田式导航（大屏 / 流量 / 日历 / 转化 / 档案）+ 时钟；中文 UI
- **大屏**：最新一期封面卡（播放 / 互动 / 分平台数字）+ 七平台粉丝合计与今日/7 日/30 日净增 + 近 30 天每日净增堆叠柱 + 三条人话「数据分析」结论 + 七张平台卡（粉丝数、日/周净增、迷你走势、该期播放）
- **日历**：上周到未来两周；期卡片带封面缩略、标题、时刻与状态（已发布 / 已定时 / 等你点发布 / 计划中）
- **单期复盘**：点大屏当期或日历卡片进入；各平台状态与播放/互动表；第 1/3/7 天「同龄对比」（拿上一期同一天数比，标出播放倍率）；分平台播放走势
- **转化**：渠道表（注册 / 会员 / 订单 / 收入）+ 每期漏斗（播放 → 注册 → 会员 → 收入）
- **流量 / 档案**：流量为各期×平台播放矩阵或条形对照；档案为文案快照与平台链接占位列表
- 样例数据：本地 JSON，约 **6–8 期**（含已发布、待发布、计划中），7 个平台（B站、抖音、小红书、视频号、YouTube、X、课程站）；封面用自绘 SVG，不使用上游素材；数字全部为虚构演示数据
- 人话洞察由本地规则生成（哪站涨粉最多、发布日是否带粉、哪站互动率最高），`bun test` 覆盖同龄对比与洞察规则
- 浅色、疏朗、大数字；Bun + Vite + React + TS；shadcn/ui；`bunfig.toml` 含 `minimumReleaseAge = 259200`
- `cd apps/maitian && bun install && bun run dev` 可跑通

### Outs

克隆/镜像上游仓库，Chrome 扩展 / CDP / 专用浏览器配置，真实平台登录与填写上传页，自动或半自动发布，创作者后台采集，飞书通知，NAS / launchd / 安装向导，账号同步，后端，i18n。

## Tasks（垂直切片）

1. **脚手架** — Vite+React+TS；`bunfig.toml`；shadcn 基础壳与顶栏导航；本 `PLAN.md` + README（灵感来源与「空跑/不接平台」说明）。
2. **假数据 + 大屏** — `src/data/demo.json`（期、平台日序列、转化）；大屏汇总、堆叠柱、平台卡、规则洞察；`bun test` 覆盖粉丝合计、净增和洞察。
3. **日历 + 单期复盘** — 日历状态色点；点击进入复盘表与同龄对比、分平台走势。
4. **转化 + 流量/档案 + 验收** — 渠道表与每期漏斗；流量/档案页；PR 附至少 1 张截图 + 1 段运行视频（大屏浏览、点进日历与复盘、再看转化漏斗）。

## Stack rationale

- **Bun + Vite + React + TS**：无后端 SPA，符合 monorepo AGENTS.md。
- **自写假数据 + SVG 封面**：对齐「一屏看七站」的卖点，又避开真实账号、采集与上游素材。
- **同龄对比用本地规则算**：这是麦田复盘里最值得演示的指标，不必接真实库。
- **shadcn/ui**：与同仓其它 demo 视觉一致；配色走浅底、大数字、轻卡片，神似但不复制上游 CSS。

## Deferred

- 响应式/手机全屏（上游有移动端大屏，本轮以桌面为主）。
